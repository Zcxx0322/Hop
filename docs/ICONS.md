# Hop 图标方案

![Hop icon](../build/icons/icon-256.png)

## 1. 设计概念

Hop 的图标是一个**终端提示符**，而不是「服务器/插头/锁」这类直白的 SSH 隐喻：

- **`>` + `_`**：命令行里最普遍的两个符号。看图标的人不需要读文字就知道「这里可以敲命令」。
- **圆角方块（squircle-ish）**：Windows 11 / macOS / 浏览器 favicon 都能自然落位；圆角半径取边长的 22.5%，接近 Windows 的 tile 视觉，又不会像纯圆形那样在小尺寸丢失画面。
- **靛蓝 → 紫罗兰对角线渐变**（`#5B6CFF` → `#934EF6`）：与前端设计令牌的强调色同一色系，应用内外的色彩语言一致；对角方向与「流」的意象呼应（连接、数据流动）。
- **左上柔光 + 内描边**：让色块读起来像一块有厚度的玻璃，而不是平涂色板。内描边（白色 16% 不透明度）保证图标在浅色桌面背景下仍有轮廓。
- **几何参数**（相对画布）：`>` 折线 `(0.315,0.315) → (0.575,0.500) → (0.315,0.685)`；下划线水平居中于折线基线 `y=0.685`，横跨 `x=0.600…0.770`；线宽 `0.082`，圆头圆角。

## 2. 小尺寸变体（≤ 32 px）

下划线与 `>` 的下臂在 32 px 以下会糊成一团（实测 16/24/32 px 均是如此）。因此生成脚本对 **≤ 32 px** 使用**简化图形**：只画 `>`，线宽加大到 `0.098` 以补偿像素化，不做下划线。

这是图标设计的通行做法（macOS/Windows 的图标系统都允许小尺寸单独出图），比「给所有尺寸共用一张图」在任务栏与 Alt+Tab 里明显更清晰。

## 3. 产出清单

| 文件 | 用途 |
| --- | --- |
| `build/icon.svg` | 矢量源文件（可缩放，用于文档/网页/favicon） |
| `build/icon.png` | 1024 × 1024 主图（Electron `BrowserWindow.icon`、Linux 包、商店素材） |
| `build/icon.ico` | Windows 图标，含 16/24/32/48/64/128/256 七个尺寸（`electron-builder` 的 `win.icon`） |
| `build/icons/icon-{16,24,32,48,64,128,256,512}.png` | 分尺寸 PNG，供 UI 内使用（窗口角落、关于页、文档） |

`.ico` 的每个尺寸都是**独立渲染**的位图，不是把 256 拉伸——Windows 任务栏因此不会出现模糊。

## 4. 生成方式（可复现）

```bash
pnpm icons          # 需要 Python 3 + Pillow + numpy
```

`scripts/make-icons.mjs` 负责找解释器（`HOP_PYTHON` → `python` → `python3` → `py`，逐个用 `import PIL, numpy` 探测），找到后调用 `scripts/make-icons.py`；找不到会给出安装提示并退出，**不影响构建**——图标资源已随仓库提交。

`scripts/make-icons.py` 的做法：

1. 用 `numpy` 按对角线插值生成 1024 × 1024（内部 2048 × 2048，2× 超采样）渐变画布；
2. 用 Pillow 的圆角矩形遮罩裁出 tile，叠加径向柔光与内描边；
3. 用 PIL 的 `line(..., joint='curve')` + 端点圆补丁绘制 `>`，用圆角矩形绘制下划线；
4. 2× 超采样后按目标尺寸用 LANCZOS 降采样（小尺寸自动切换简化图形）；
5. 用 Pillow 的 ICO 插件把 7 张独立位图写入同一个 `.ico`（`append_images`）。

全部参数集中在脚本顶部的常量里（`TOP` / `BOTTOM` / `RADIUS_RATIO` / 折线坐标），改配色或比例只需改一处再 `pnpm icons`。

## 5. 与应用的接入点

- **窗口/任务栏**：`src/main/window.ts` 的 `windowIcon()` 在 `build/icons/icon-256.png` 存在时把它交给 `BrowserWindow`（dev 与 Linux 有效）；安装后的可执行文件图标由 `electron-builder.yml` 的 `win.icon: build/icon.ico` 决定。
- **应用内**：前端 `src/components/ui/Logo.tsx` 使用同一套渐变与折线，视觉上与图标同源。
- **品牌色校验**：图标渐变端点与 `src/styles/tokens.css` 的极光强调色一致，切换强调色时图标保持品牌色不变（图标是资产，不参与换肤）。

## 6. 使用规范

- 最小可视尺寸 **16 px**；小于 32 px 使用简化图形（脚本自动处理）。
- 保留四周 **≥ 8%** 的安全边距（当前设计留白约 12%），不要把图标裁到内容边缘。
- 不要给图标加投影或描边来「适配」深色背景——内描边与渐变已经保证在浅色/深色背景下都成立。
- 单色场景（如印刷、单色任务栏）可使用 `build/icon.svg` 的 `>` 与 `_` 两个元素，填充为纯白或纯黑，省略背景 tile。
